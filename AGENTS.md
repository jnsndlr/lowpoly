# Working on Tideways

Use **quick mode** by default. Work on a branch and get the gameplay change into the running game quickly. Use the smallest check that tells you whether the idea works. Defer comprehensive testing, naming polish and unrelated cleanup while the design is moving. Draft PRs and short stacks are welcome.

Switch to **merge mode** when the author asks to land the work. Own cleanup, validation, CI results and any fixes through the final PR head. Both Paul and Jon can authorize their own merges when they have repository write access. A draft or a request to prototype is not an instruction to merge.

Read [the team workflow](docs/workflow.md) for the merge steps and how to coordinate shared changes.
